# Limitations

- Not production-ready, not regulator-approved, and not suitable for a real decision.
- SQLite and a local directory are single-machine stores.
- The hashing embedder is deterministic and does not have the recall of a trained embedding model. Keyword search and structured claims carry the demonstration.
- The composer is a template over claims. It will not write a free-form essay, and it should not.
- Charts are Streamlit line charts. They are labelled in text so status is not communicated by colour alone, but they are not a management-information product standard.
- Quarantined files are recorded. There is no malware engine behind the scan placeholder.
- Report review records a note. It does not approve anything.
- Some portfolio screens show a count of ingestion failures without opening another customer's file.
- Evaluation coverage is the seeded question set, not a statistical sample of all possible questions.
- Docker runs the same hackathon profile. It does not add production controls.
