# Interface design system

Match the workflow diagram in the idea submission. The tone is a credit-committee paper on screen, not a consumer app and not a purple technology demo.

## Colour

Taken from the diagram: orange headers, red-orange links, warm grey panels, off-white ground.

| Token | Hex | Use |
| --- | --- | --- |
| Orange | `#E36F1E` | Primary actions, stage headers, key marks |
| Orange deep | `#C45112` | Pressed states, important numbers |
| Red | `#B42318` | Escalation, deterioration, overdue |
| Red wash | `#F8E8E4` | Alert panels |
| Ink | `#2C2825` | Body text |
| Brown title | `#8C3E16` | Product title, as in the diagram |
| Muted | `#6F6862` | Labels, captions |
| Line | `#E4DDD6` | Card borders |
| Grey panel | `#F3EFEA` | Page ground |
| Grey card | `#F7F4F0` | Secondary panels |
| White | `#FFFcf9` | Primary cards |

Do not use a second bright hue. Green is reserved for the single word "Current" or "Stable", and it stays desaturated (`#3E6B45`).

## Type

- Titles: Source Serif 4, or the nearest installed serif.
- Interface and tables: Source Sans 3.
- Figures: tabular lining numbers.
- Labels: 11px, uppercase, letter-spacing 0.08em, muted.

## Layout

- Left rail, 232px, warm charcoal `#3A342F`. Active item is an orange bar, not a filled pill across the whole row.
- Page title in the brown title colour. One sentence under it explaining the job of the page.
- Cards with a 1px line, 12px radius, no heavy shadow.
- A five-stage strip under the title, repeating the diagram as orange boxes with a short arrow between them: Trigger, Sources, Agents, Pack, Access. All five boxes stay orange.
- A citation opens in a column beside the paragraph, so the sentence stays readable.
- Do not copy the globe mark from the diagram. The wordmark is “BEA AI”, with “AI” in orange.
- The group pack reads top to bottom, like a paper, with the seven sections in the submission order.
- Citations are small orange text buttons. Opening one shows the source name, date, passage and agent. It does not navigate away.

## Roles

The same screens exist for every role. The landing emphasis changes.

- CRO opens on the portfolio.
- Credit committee opens on the pack.
- RM opens on alerts and the monitoring plan for entitled groups.

## Writing

- British spelling in the interface if the surrounding bank language is British; the submission itself is in international English. Stay consistent inside one build.
- Dates as 14 Oct 2026. Money as HKD 1,250,000, with the currency code.
- Do not fill empty states with invented zeros.
