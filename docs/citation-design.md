# Citations

Every material claim carries one or more citations.

A document citation shows the title, filename, document identifier, customer, risk domain, reporting date, version, authoring function, and the page, sheet and cell range, or the Word section and paragraph, when the parser captured them. The UI button and the HTML report link open `/source?document_id=...`. The source viewer renders the PDF page, the Excel sheet or the Word paragraphs beside the locator metadata. The filesystem path is not shown.

A database citation shows the source system, table, record identifier, as-of date, calculation timestamp, unit, original currency and HKD equivalent.

Example shape:

`[Interim Credit Review - Apex Harbour Trading Limited, page 6, version 3, reporting date 30 Sep 2026]`

Citations cannot be switched off by the user or by text inside a document.
